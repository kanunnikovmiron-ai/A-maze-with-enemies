# AGENTS.md — гид по проекту

Что бы сделать коммит в GIT обязательно получи разрешение, запрещено делать коммит в GIT без согласия пользователя.

2D-игра «Лабиринт» (vanilla JS, без сборки и зависимостей). Запуск — открыть `index.html` в браузере.

## Структура

- `index.html` — разметка, HUD, экраны меню/уровня, подключение скриптов.
- `style.css` — стили.
- `levels.js` — уровни 0-11 (15×15; уровень 0 — «Обучение» `tutorial: true` с placements (ключи/враги) и гарантированной секретной комнатой через `secretEntrance`, уровень 11 — арена босса 20×20).
- `navigation.js` — переключение экранов, запуск/перезапуск игры, настройки сложности.
- `script.js` — глобальная инициализация, `initGame()`, `nextLevel()`, `restartLevel()`, `getSettings()`.
- `js/` — классы игры:
  - `Game.js` — оркестратор: лабиринт, враги, ключи, секретная комната, туман, победа/поражение.
  - `Player.js` — игрок: ход, HP (3), урон, меч, коллизии с врагами/огнём.
  - `Enemy.js`, `PatrolEnemy.js`, `BossEnemy.js` — враги (круглые, стражники, босс 2×2 с HP 6).
  - `Renderer.js` — отрисовка и камера (вьюпорт 15×15, игрок в центре, скролл на арене 20×20).
  - `PathFinder.js` — BFS-пути и проходимость.
  - `*Config.js` — настройки игрока/врагов/финиша/ключей по сложности.
- `shop.js` — магазин и монеты: кошелёк/инвентарь в localStorage (`miron_wallet`, `miron_inventory`), награды `COIN_REWARDS`, товары `SHOP_ITEMS`, функции `getWallet/setWallet/addCoins/getInventory/saveInventory/getShopBonuses/canBuy/buyItem`.
- `audio/` — аудиофайлы.

## Конвенции

- Комментарии в коде — на русском; в новые коммиты/правки без явной просьбы комментарии не добавлять.
- Игрок: `maxHp/hp = 3`, смерть при 0 HP, неуязвимость полностью блокирует урон.
- Босс: блок 2×2, HP 6/6, победа после 6 ударов мечом, финиш открывается после победы.
- Секретная комната (15×15) на каждом уровне: вход через трещину в стене, внутри меч, свет, огоньки. На «Обучении» (индекс 0) вход задан через `secretEntrance` — комната гарантирована (`tryCreateSecret` даёт `chance = 1` на tutorial).
- Секретный босс (`SecretBossEnemy.js`): розовое сердце 1×1, HP 10, кидает бомбы (⚠ → 🔥, у бомб `bomb: true` — своя текстурка: спрайт с фитилём в фазе warn и крестовый взрыв в фазе fire), взрыв — крест лучами до стены/края карты; победа мечом = 30 монет (только за ПЕРВОЕ поверженное сердце на уровень, `game.secretBossCoinsGranted`; дальние сердца — без награды). Два пути в редакторе: 1) инструмент «💗 Секретный босс» — ставит сердца прямо на проходимые клетки карты (можно несколько, босс сражается в основном лабиринте); 2) инструмент «💥 Арена секр. босса» — трещина на стене (`level.secretBossEntrance`, гарантирован), ведёт на открытую арену 15×15; там игрок получает боевые HP `max(3, maxHp)` и восстанавливает исходные при выходе. На обычных уровнях случайная розовая трещина (шанс ~15%, на «Обучении» нет) ведёт на ту же арену. Музыка секретного босса (`playSecretBossMusic`) играет не только на арене, но и на уровне, где есть живое сердце на карте; после повержения последнего сердца музыка останавливается (`resumeLevelMusic` — приоритет сердца над босс-музыкой).
- Магазин — отдельная комната-уровень (10×10, открытое пространство без лабиринта) на каждом уровне: вход через дверь-проход в стене; внутри 3 пьедестала (меч 50, +HP 30 до 3 раз, улучшенный меч 100, требует меч); покупка — подойти к пьедесталу (автопокупка), выход — через портал у входа. Монеты: враг 3, страж 5, босс 30, прохождение 10. Покупки постоянны (localStorage). На «Обучении» (индекс 0) бонусы магазина не применяются (`applyShopBonuses` игнорирует tutorial). Улучшенный меч наносит боссу 2 урона за взмах.
- Камера (`Renderer.js`): `viewCols/viewRows = 15`; при лабиринте 15×15 канвас = весь лабиринт (без скролла), на арене 20×20 — скролл с центрированием игрока и клампом по границам мира.
